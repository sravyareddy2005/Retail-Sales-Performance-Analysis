# Retail Sales Performance Analysis

## Objective
Analyze retail sales data and extract useful business insights using Python and NumPy.

## Technologies
- Python
- NumPy
- Google Colab

## Analysis Performed
- Total Sales
- Average Sales
- Median Sales
- Highest and Lowest Sales
- Standard Deviation
- Variance
- Total Quantity Sold
- Average Quantity per Transaction
- Maximum Quantity per Transaction

## Results
- Total Sales: ₹456,000
- Average Sale: ₹456
- Median Sale: ₹135
- Highest Sale: ₹2,000
- Lowest Sale: ₹25
- Total Quantity Sold: 2,514
- Average Quantity per Transaction: 2.514
